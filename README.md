# Brijbhushan — Portfolio

A responsive personal portfolio website built with plain HTML, CSS, and JavaScript.

## View it locally

Open `index.html` in any modern browser. No build tools or dependencies are required.

## Personalize it

- Replace the placeholder contact address (`your.email@example.com`) in `index.html`.
- Update the About, Skills, and Projects sections with your own details and work.
- The site is ready to publish with GitHub Pages or another static hosting service.
